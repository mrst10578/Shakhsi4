# Shakhsi4 | Independent Panel Econometrics

Two independent research tracks based on datasets received via email: AI investment/patents and the labor market (30 countries, 2016–2024); digital economy, growth, and labor productivity (47 countries, 2005–2022).

**This repository is public. Raw emailed spreadsheets, research manuscripts, and unverified source materials are intentionally not published.** Source workbooks are supplied locally to run the analysis.

Pre-estimation diagnostics (stationarity, multicollinearity, panel structure, instrument strategy) and post-estimation checks (Hansen, Arellano-Bond AR(1)/AR(2), instrument count, difference-in-Hansen when available) are complementary and should not be conflated. Dynamic GMM estimates should not be reported as complete unless the Stata scripts are actually executed and their outputs audited.

This repo and its Linear project are isolated from Shakhsi2/Shakhsi3.
